# Course Selling App

A web application for creating, managing, and selling online courses. This platform enables instructors to publish courses and students to browse, purchase, and access educational content.

## Features

- User authentication and roles (instructor, student, admin)
- Course creation and editing for instructors
- Course browsing and purchase for students
- Secure payment integration
- Video and file hosting for course content
- Progress tracking for students
- Dashboard for instructors and students
- Admin panel for managing users, courses, and transactions

## Getting Started

1. **Clone the repository:**
    ```bash
    git clone https://github.com/viveklele/course-selling-app.git
    cd course-selling-app
    ```

2. **Install dependencies:**
    ```bash
    npm install
    # or
    yarn install
    ```

3. **Configure environment variables:**
    - Copy `.env.example` to `.env` and update the values as needed.

4. **Run the application:**
    ```bash
    npm start
    # or
    yarn start
    ```

5. **Access the app:**
    - Open your browser and navigate to `http://localhost:3000` (or the port specified in your config).
